
# 🌿 MindDates — Mental Wellness Calendar
## 💭 About the Project
MindDates is a simple mental wellness calendar that helps you track your daily moods and record it in one place.

## ✨ Features
- 📅 Interactive calendar with month navigation
- 😊 Daily mood tracking
- 📝 Personal notes and reflections
- 📊 Monthly mood statistics and insights
- 💾 Saves entries locally using browser localStorage
- 🔒 No account required

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Browser localStorage

## 🚀 How to Use
1. Open the MindDates website.
2. Select today or a previous date.
3. Choose your mood and add an optional note.
4. Click **Save check-in** to save your entry.
5. View your mood history and monthly statistics.

## 🔐 Privacy
Your entries are stored in your browser's localStorage. 
They do not automatically sync across devices.
